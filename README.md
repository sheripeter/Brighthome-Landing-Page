
# BrightHome Services

A responsive small-business website for a fictional
home and office cleaning company.

## Project Overview

BrightHome is a front-end website designed to present
cleaning services and allow visitors to complete a
contact form.

## Features

- Responsive navigation
- Hero section with professional photography
- Service cards with images
- About and contact sections
- JavaScript form validation
- Responsive desktop, tablet and mobile layouts

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

- Semantic HTML structure
- CSS Flexbox and Grid
- Responsive design and media queries
- DOM manipulation
- JavaScript form validation
- Basic accessibility improvements

## Important Note

This is a front-end demonstration project.
The contact form validates user input but does not
send or store enquiries.

## Project Status

Completed front-end practice project.
